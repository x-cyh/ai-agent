【海報標題】
人生故事書

【副標】
組別／組員：個人專題　日期：2026-06-24

【區塊 1 · 專題介紹】
- 專題名稱：人生故事書
- 一句話：留下最想說給孩子聽的一段人生故事
- 主要使用者：父母
- 想解決的問題：小孩常常不知道父母的經歷，缺乏理解

【區塊 2 · 左欄與右欄互動】
- 左欄自訂頁：人生故事書（10_Life_Story.py）
- 左欄傳給 Agent：用 format_extra_context 把左欄三區塊（故事主線／訪談進度筆記／事實）打包成摘要文字
- Agent 寫回哪裡：回應結尾的【NOTES】／【FACTS】區塊被左欄自動 append／merge；最終 .md 存到 story_outputs/
- 完整例子：父母輸入「北上工作」→ Agent 沿主線追問 → 每輪 NOTES／FACTS 自動寫回左欄 → 說「可以整理成故事了」→ 產出 .md

【區塊 3 · 成果】
- 人生故事書：父母輸入故事主線 → Agent 採訪式引導（背景→開端→衝突→決定→結果→意義→留給孩子的話）→ 自動寫回左欄筆記／事實 → 產 .md 到 story_outputs/ → 匯出 Word / PDF

【區塊 4 · 創新／亮點】
- Agent 回應自動寫回左欄：Agent 回應結尾的【NOTES】／【FACTS】區塊會自動 append／merge 到左欄的「訪談進度筆記」與「已蒐集事實」，父母不需要手動抄錄
- 採訪式引導流程：沿「背景→開端→衝突→決定→結果→意義→留給孩子的話」七個階段依序追問，把零散的記憶整理成一段完整故事

【區塊 5 · 技術含量】
- Streamlit（左欄 UI 框架）
- Agent Studio（右欄 LLM 對話）
- JSON 狀態檔（studio_shell/data/ 儲存故事索引與進度）
- 【NOTES】／【FACTS】標記解析（Agent 回應自動寫回左欄的機制）
